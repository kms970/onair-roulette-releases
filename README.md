# ON AIR Roulette

투네이션·유튜브 방송 이벤트를 OBS 룰렛과 마인크래프트 패널티에 연결하는 Windows 프로그램이에요.

[최신 설치파일 받기](https://github.com/kms970/onair-roulette-releases/releases/latest)

릴리스 화면에서 이름이 `Setup.exe`로 끝나는 파일을 받으세요. Windows 10·11 64비트용이며 Java 25가 함께 설치돼요. GitHub 계정 없이 받을 수 있어요.

## 처음 실행하기

1. 이전 앱이 켜져 있으면 **룰렛 → 룰렛 종료**로 꺼요.
2. 받은 설치파일을 더블클릭해요.
3. 마크를 연동하려면 **마인크래프트 → 맵 · 서버 준비**에서 맵 목록을 고르거나 맵 ZIP을 넣어요.
4. 맵 이름을 확인하고 마인크래프트 약관에 동의한 뒤 **자동 준비하고 서버 켜기**를 눌러요.
5. 마크에서 앱에 표시된 주소로 접속해요. 자세한 사용법은 앱의 **도움말 → 처음 연결하기 · 사용 안내**에서 볼 수 있어요.

유튜브·투네이션 계정은 각자 연결해야 해요. 설치파일에는 개인 계정이나 방송 기록이 들어 있지 않아요.

## 자동 업데이트

1.13.0 이하에서 쓰던 사람은 1.14.0 이상을 처음 한 번 직접 설치해 주세요. 그다음부터 앱을 새로 켜거나 **도움말 → 업데이트 확인**을 눌렀을 때만 새 버전을 확인해요. 실행 중에 주기적으로 확인하거나 갑자기 설치하지 않아요.

다운로드가 끝나면 60초 동안 안내하고 업데이트해요. 1.22.0부터는 **지금 업데이트**로 대기를 생략할 수 있어요. **이번에는 건너뛰기**를 누르거나 안내 창을 닫으면 다음 앱 재실행이나 직접 확인 전까지 설치하지 않아요. 앱에서 켠 마크 서버는 월드를 저장한 뒤 종료하고, 업데이트가 끝나면 같은 맵을 이어서 켜요. 마크 게임에서는 다시 접속해 주세요.

설정·기록·저장된 대기열은 유지해요. 별도로 연 마크 서버는 종료하지 않아요. 직접 입력한 외부 서버 RCON 비밀번호는 업데이트 뒤에 다시 입력해야 해요. 앱이 꺼져 있는 동안의 방송 알림은 연결 서비스가 다시 보내지 않으면 놓칠 수 있어요.

`.blockmap`과 `latest.yml`은 자동 업데이트에 쓰는 파일이라 직접 실행할 필요가 없어요.

이 저장소는 설치파일 배포용이에요. 프로그램 소스를 따로 올리지는 않아요.

## 게임 글자와 OBS 집계

**방송 · 패널티 → 인게임 글자 색**에서 진행도와 실드의 색을 각각 바꿔요. 기본 위치는 게임 단축바 위이며, 아래 배치 설정에서 옮길 수 있어요.

**좋아요 · 구독자 OBS에 넣기**에서 주소를 복사해 OBS 브라우저 소스로 추가하세요. 둘 다 표시하면 800×100, 한 항목만 표시하면 420×100이에요. 항목을 각각 골라 소스를 하나씩 만들면 따로 배치할 수 있어요.

## 게임 안의 진행도 간편 설정

1.25.0부터 앱이 만든 마크 26.2 서버에서는 **간편 설정 → 마크 접속 → 리소스팩 ‘예’**로 시작해요. 모드나 OBS 진행도 소스는 필요 없어요.

1. **마인크래프트 → 방송 · 패널티 → 인게임 진행도 배치**를 열어요.
2. **기본 배치로 간편 설정**을 눌러요. 처음 한 번은 서버를 저장하고 다시 켜요.
3. 마크에서 서버에 접속하고 리소스팩 안내가 뜨면 **예**를 눌러요.

위치나 글자는 **위치·글자 바꾸기**를 펼쳐 고른 뒤 **게임에 적용**을 눌러요. 게임이 같은 서버로 잠깐 자동 재접속해서 새 배치를 받아요. 이후 배치 변경에는 서버 재시작이나 F3+T가 필요 없어요. 체크포인트·실드·아이템은 유지돼요.

가로 게임 화면 가운데 9:16 영역을 기준으로 배치해요. 화면 크기는 자동으로 읽으며, 잘 맞지 않을 때만 접힌 설정에서 직접 입력해요. **기본 위치로 되돌리기**를 누르면 단축바 위 기본 글자로 돌아가요.

직접 RCON으로 연결한 서버는 수동 적용을 사용해요. 리소스팩 준비 후 마크 설정에서 ON-AIR-HUD를 켜고, 이후 변경은 저장 후 F3+T예요. 별도 서버 리소스팩 URL은 덮어쓰지 않아요. 맵 폴더의 resources.zip은 원본을 보존하고 HUD 팩에 합쳐 보내요.

연동팩은 프로토콜 14예요. 1.24.0을 사용했다면 맵을 초기화할 필요가 없어요.
